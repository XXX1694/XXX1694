### 👋 About me

- 📱 Mobile Engineer at **BCC-HUB** (Bank CenterCredit), building a banking **SuperApp**
- 🚀 **5+ years** in mobile development, **20+ digital products** shipped across fintech, EdTech, fitness and e-commerce
- 🧩 I like the hard parts of mobile: app architecture at scale, native bridges, performance and rendering
- ✍️ I write deep dives on Flutter internals on [Medium](https://medium.com/@serikbay.a04)

### 🛠️ What I do

| | |
|---|---|
| **Flutter at scale** | SuperApp and Mini-App architecture (mPaaS), multi-engine setups, design systems with reusable component libraries |
| **Native & biometrics** | Custom Flutter plugins in Kotlin and Swift; a unified biometric module on top of LunaID (VisionLabs) and OZForensics SDKs for facial verification |
| **Native apps** | Android with Kotlin + Jetpack Compose, iOS with Swift |
| **Backend** | Go services with Chi, PostgreSQL, Redis and Docker |
| **Delivery** | GitLab CI, Fastlane, Sentry, App Store / Google Play releases |
