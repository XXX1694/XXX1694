### What I do

**Flutter at scale** — SuperApp and Mini-App architecture (mPaaS), multi-engine setups, native bridges, design systems with reusable component libraries.

**Native & biometrics** — Custom Flutter plugins with Kotlin/Swift; built a unified biometric module integrating LunaID (VisionLabs) and OZForensics SDKs for facial verification.

**Edge AI** — Quantized LLMs on mobile, TFLite / MLC, token streaming without freezing the UI.

**Backend** — Go services with Chi, PostgreSQL, Redis and Docker.
